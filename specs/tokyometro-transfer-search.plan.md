# 東京メトロ 改札外乗換検索 テスト計画書

## 1. 検証目的

東京メトロ線内で完結する経路について、次の公開された振る舞いをブラックボックスで検証する。

- 東京メトロが指定する改札外乗換だけを使用し、改札外乗換回数が最大の経路を表示すること。
- 表示経路の実走営業キロが、各乗車区間の営業キロの合計と一致すること。
- 運賃計算用最短営業キロが、実際の乗車経路ではなく発駅・着駅間の最短キロ程と一致すること。
- 改札外乗換駅までの運賃が着駅までの運賃を上回る場合、その差額を返さない規則が最終運賃へ反映されること。
- IC カード運賃ときっぷ運賃が、該当するキロ帯の普通旅客運賃と一致すること。
- 同じ経路が複数の検索結果として表示されないこと。
- 他社線を含む区間や、東京メトロが指定していない改札外乗換が混入しないこと。

## 2. 対象と前提

- 対象画面: `/tools/tokyometro-transfer-search`
- 対象範囲: 東京メトロ9路線内で完結する経路
- 対象運賃: 大人の普通片道運賃（ICカード、きっぷ）
- 情報基準日: 2026年7月22日
- 各改札外乗換は60分以内に行う前提とする。乗換時間の入力欄がないため、60分超過時の打切り計算は対象外とする。
- 経路は同じ駅を再訪しない単純経路として扱う。路線は、異なる区間であれば再度利用してよい。
- 結果の表示順は検証しない。代表経路が結果集合に含まれること、各経路の値、および集合の一意性を検証する。
- 実装コード、実装定数、実装の計算関数を期待値の算出に使用しない。

### 3.2. 営業キロ

- **実走営業キロ**: 代表経路の各路線内の乗車区間を、旅客営業規程の別表第1号表「営業キロ程」で求めて合計する。乗換の徒歩区間は加算しない。
- **運賃計算用最短営業キロ**: 発駅から着駅までの東京メトロ線内の最短キロ程を使用する。実走営業キロは使用しない。
- 運賃計算では、旅客営業規程第13条に定める区間は同条の運賃計算キロ程へ置き換える。
- 画面には小数第1位までのキロ程を表示し、運賃帯の判定時だけ1km未満を1kmへ切り上げる。

出典: [旅客営業規程（2026年6月14日施行）](https://www.tokyometro.jp/ticket/terms/pdf/ryokyaku_eigyo_260614.pdf) 第8条、第13条、別表第1号表

### 3.4. 改札外乗換を含む最終運賃

各経路の最終運賃は、次の各運賃の最大値とする。

1. 発駅から着駅までの最短営業キロに対応する運賃
2. 発駅から、各改札外乗換で最初に出場する駅までの最短営業キロに対応する運賃

異駅名の乗換では、乗換前に出場する側の駅を計算対象とする。たとえば「有楽町から日比谷へ」の乗換は有楽町まで、「日比谷から有楽町へ」の乗換は日比谷までを計算する。

根拠: 東京メトロの「営業のご案内」は、改札口をいったん出場する乗換駅では発駅から乗換駅までの運賃を収受し、その運賃が着駅までの運賃を上回っても差額を返さないとしている。

出典: [営業のご案内](https://www.tokyometro.jp/support/guide/operation/index.html)

## 4. 経路表記

- 路線記号: `G` 銀座線、`M` 丸ノ内線、`H` 日比谷線、`T` 東西線、`C` 千代田線、`Y` 有楽町線、`Z` 半蔵門線、`N` 南北線、`F` 副都心線
- `>`: 次の乗車区間または乗換へ進む
- `[外]`: 改札外乗換
- `[内]`: 改札内乗換

## 6. 重複判定方法

各経路を次の形へ正規化し、正規化キーの重複を検出する。

```text
乗車駅
| 路線記号:乗車駅>降車駅
| 乗換種別:乗換前駅/乗換前路線>乗換後駅/乗換後路線
| ...
| 降車駅
```

判定時は次を正規化キーへ含める。

- 乗車区間の順序
- 路線
- 各区間の乗車駅・降車駅
- 乗換前後の駅・路線
- 改札外乗換か改札内乗換か

次は正規化キーへ含めない。

- `ROUTE 001` などの表示番号
- 運賃、営業キロ、乗換回数の表示値
- カードのDOM属性、内部ID、表示用スタイル

全カード数と正規化キーの集合サイズが一致すれば重複0件と判定する。同じ正規化キーで運賃や営業キロだけが異なる場合も、重複かつ計算不整合として失敗とする。

## 7. 合否基準

- TC-01〜TC-07の必須出力値がすべて一致すること。
- 営業キロは小数第1位まで完全一致で比較すること。
- 運賃は円単位で完全一致すること。
- 経路集合は順不同で比較すること。
- 代表経路は結果内に1件だけ含まれること。
- 重複、非公式の改札外乗換、他社線混入が1件でもあれば不合格とする。
